Menstrual Flux Cycle Planner
Effective 24 July 2026

Privacy notice

Version 0.1 of the Cycle Planner is a local-only application. It does not send cycle records to Menstrual Flux, Nalin Dhiman, IIT Mandi or a third-party analytics service.

Information stored on your device

The application stores the adult-age acknowledgement, recorded period start dates and whether example mode is active. These values are kept in browser local storage for this website.

Information not requested

The application does not request a name, email address, date of birth, precise location, contacts, advertising identifier, symptom diary, sexual activity, pregnancy intention or fertility information.

Sharing and research

There is no research-upload function in this release, and cycle dates are not sold or shared. A future research contribution feature would require a separate explicit consent process and would not be enabled by this notice.

Hosting and request information

GitHub Pages, Cloudflare and related delivery infrastructure may receive ordinary web-request information such as IP address, browser user agent, requested files and security-event metadata. A host may set a strictly infrastructural security cookie. The planner does not place period start dates in URLs, cookies, request bodies or analytics events, so these hosting requests do not contain the local cycle record.

Your controls

The Privacy screen can export a readable JSON copy or erase the local planner record. Browser settings can also remove site data. Private browsing may erase the record automatically when the session closes.

Security boundary

Local-only storage removes a central cycle database but does not protect against another person who can access your unlocked browser profile or device. Device passcodes and browser-profile controls remain important.

Age and scope

This release is intended for adults aged 18 or older. It provides rough period-planning estimates and is not intended for fertility, contraception, diagnosis, treatment or emergency decisions.

Contact and copyright

Project questions can be raised through the public repository issue tracker. Do not include personal health information in a public issue.
