    How this estimate is built

    1. 1Measure intervals between recorded starts.
    2. 2Give recent intervals slightly more weight.
    3. 3Use a population anchor when history is short.
    4. 4Widen the window when timing varies.
    Deliberate boundary

    This app does not estimate ovulation or “safe days.”

    Calendar timing alone cannot establish fertility. The planner is for everyday preparation and record keeping, not pregnancy prevention or conception decisions.
